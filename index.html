Install it in four steps

It takes about two minutes, and you don't need to be technical.

  1. Download the installer

    Select Download for Windows. The file is called RAID-Setup.exe.

  2. Open it and allow it through SmartScreen

    Windows shows a blue warning for apps it hasn't seen before, including new ones from your own office. Select More info, then Run anyway. Try it below.

    Windows protected your PC

    Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

    App:
    RAID-Setup.exe
    Publisher:
    Unknown publisher

    Setup opens next. Only choose Run anyway for a file you downloaded from this page or got from your CDRRMO office.

  3. Follow the setup

    Select Next, then Install. Tick Create a desktop shortcut if you'd like one. .NET is already included, so there's nothing else to add.

  4. Open R.A.I.D

    Start it from the desktop shortcut or the Start menu. It needs an internet connection to load live reports, responder locations and the map.

Questions people ask before installing

Windows says the app is unrecognized. Is it safe?

The installer isn't code-signed yet, so Windows warns about it the way it does for any new app. If you downloaded it from this page or got it from your CDRRMO office, select More info, then Run anyway. If a checksum is shown next to the download, you can confirm the file matches it first.

Windows still blocks the file. What now?

Right-click the file and choose Properties. On the General tab, tick Unblock at the bottom, select OK, then open the file again.

Do I need administrator rights or .NET?

No. The installer sets R.A.I.D up for your Windows account only, and everything it needs, including .NET, is already inside it.

Does it need an internet connection?

Yes. R.A.I.D reads live reports and responder locations and loads the map online, so the PC needs a working connection while you use it.

Android says it can't install the app. What now?

Open the downloaded file and, when Android asks, allow your browser or Files app to install unknown apps. Then tap Install. Only do this for files from this page or from your CDRRMO office.

How do I update to a newer version?

Download the newer installer or APK from this page and run it. It upgrades the existing install, so you don't need to uninstall first.

How do I remove it?

On Windows, open Settings, go to Apps, find R.A.I.D and select Uninstall. On Android, press and hold the app icon and choose Uninstall.
